GUIDE DE L’ÉQUIPEMENT

Option : Armure, Règles Rapides

Pour ceux qui souhaitent des règles rapides et simples pour les armures, utiliser ce qui suit. Les Armures sont séparées en trois groupes : Légères, Moyennes et Lourdes. Les Légères sont principalement en cuir, les Moyennes en maille et les Lourdes en plate.

Sacs et Contenants

Les Possessions peuvent être rassemblées dans des sacs à dos, des sacs et des bourses, pour les rendre plus faciles à transporter. Le Tableau ci-après indique la valeur d’Encombrement pour un sac ou un autre contenant (Enc) et l’Encombrement que le contenant peut détenir (Contenu). Vous ne considérez que l’Enc pour déterminer le nombre de Points d’Encombrement transportés. Le bon sens dicte quels objets peuvent être transportés dans le contenant (par exemple, les hallebardes ne peuvent pas être transportées dans des sacs à dos).

Baril : Capacité : 145 litres de liquide.

Besace : considéré comme « porté » si vous le mettez en bandoulière.

Cruche : Capacité : 4/5 litres de liquide. Flasque : Capacité : 1 demi-litre de liquide. Grand sac : nécessite une main pour être transporté (ou deux mains s’il est plein).

Outre : capacité : 4/5 litres de liquide. Sac : nécessite 1 main pour être transporté. Sac à dos : considéré comme « porté » si vous le fixez à votre dos.

Tonneau : Capacité : 45 litres de liquide.
