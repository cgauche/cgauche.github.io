Régence impériale d'Ubersreik

Pouvoir occupant à Ubersreik post-putsch impérial contre la maison Jundfreud (2509 IC). Façade militaire = général Jendrick von Dabernick. Pouvoir réel = Emmanuelle Nacht, régente impériale + maîtresse-espionne pour le compte de l'empereur.

Identité

  • Type : Régence d'occupation impériale (autorité dérivée de Karl-Franz).
  • Base : Ubersreik, palais de la ville (ancienne demeure Jundfreud confisquée).
  • Période : depuis ~2509 IC (Edit impérial), encore active fin 2512 IC.
  • Allégeance : Empire / maison Holswig-Schliestein (Karl-Franz Altdorf).
  • Statut : [ACTIF — fragile]. Tensions structurelles avec loyalistes Jundfreud (résistance populaire) + maisons nobles candidates (Bruner/Aschaffenberg/Holzenauer/Saponatheim). Toutes affaiblies post-S20.
  • Tags : #RégenceUbersreik #EmmanuelleNacht #Dabernick #OccupationImpériale #KarlFranz #Altdorfers #Espionnage

Composition

Façade publique (militaire)

  • Général Jendrick von Dabernick : envoyé impérial officiel. Costume militaire formel à toutes les apparitions. Coupe de cheveux à double queue de comète (symbole sigmarite/impérial). Présent au bal masqué S20.
  • Garnison aldorfer : armée impériale stationnée dans la grande tour de guet (capitaine Blucher) + autres positions stratégiques.
  • Watch Captain Andrea Pfeffer (canon RN&HD ch.7) : sous-staffée, recrute des bénévoles pour patrouilles. Position ambiguë (entre administration impériale et police locale).

Pouvoir réel (occulte)

  • Emmanuelle Nacht : régente impériale, vraie dirigeante d'Ubersreik. Officiellement « représentante diplomatique » ou similaire. Réellement, maîtresse-espionne — pilote un réseau d'informateurs et de tueurs discrets.
  • Filianore : ex-espionne de Nacht, perdue contact à Bögenhafen, récupérée S14. Mission post-S14 : opérations spéciales (empoisonnements ciblés, infiltrations).
  • Réseau d'informateurs anonymes : non détaillés à table. Probablement infiltrés dans toutes les maisons nobles + clergé + corporations marchandes.
  • Agents de terrain hors Ubersreik : Andreas Wagenkneicht (S21) probable faux-nez Nacht chargé d'exfiltrer le groupe vers Altdorf — non confirmé table.

Doctrine / méthodes

  • Maintenir l'occupation impériale sans déclencher de soulèvement ouvert.
  • Affaiblir simultanément toutes les familles candidates au titre de seigneur d'Ubersreik (afin qu'aucune ne puisse s'imposer comme alternative). Confirmé S20 : Filianore empoisonne Andreas Bruner sous ordre Nacht, et Nacht assiste au bal incognito (chevalier panthère) pour superviser.
  • Espionnage interne : Nacht surveille les nobles ; toute conspiration locale est repérée et neutralisée.
  • Coopération sélective avec les PJ : Nacht efface les ennuis judiciaires de Bögenhafen (S14) en échange du contrôle continu de Filianore.

Mission externe (Main Pourpre)

  • Filianore avait été envoyée à Bögenhafen pour enquêter sur Kastor Lieberung, agent important de la Main Pourpre (S14).
  • → La Régence d'Ubersreik enquête activement sur la Main Pourpre. C'est l'une des rares cellules officielles anti-Tzeentch dans le Reikland (cohérent avec le réseau réduit décrit dans Lieux/Altdorf.md).
  • Hypothèse forte : Nacht est en contact avec Adolphus Kuftsos (avant sa mort S8) et probablement Quintus Fassbinder à Altdorf. Réseau anti-Main Pourpre coordonné.

Apparitions par session

  • [S14] — Filianore conduite au palais. Révélation espionne + Kastor. Nacht libère Pathsokar, éponge Bögenhafen.
  • [S16] — Mission Vielfrass. Nacht exige neutralité absolue dans la tension Altdorfers/loyalistes.
  • [S20] — Nacht présente incognito en chevalier panthère au bal masqué (accompagnant Dabernick). Surveille l'effondrement des familles candidates qu'elle a partiellement orchestré.
  • [S21] — Nouvelle mission complexe briefée à Filianore pour Altdorf. Wagenkneicht probable agent Nacht d'exfiltration.

Ce que les PJ savent

  • Nacht = vraie patronne d'Ubersreik, dirige Dabernick.
  • Filianore = son espionne, longue date.
  • Kastor Lieberung = agent important Main Pourpre, enquête en cours.
  • Bögenhafen : ennuis épongés par Nacht.
  • Sera contactée pour la nouvelle mission à Altdorf.

MJ-only

  • Agenda exact de Nacht : canon = loyaliste impériale anti-Tzeentch. MJ peut basculer plus ambigu : agent double ? Agente Sigmar radical ? Agente Tzeentch retournée (très improbable mais théoriquement possible). À garder ouvert.
  • Sort post-S22 de Nacht : pas activé table. Cf. fil Arc 7 « volonté Jundfreud reprendre Ubersreik par les armes » (S57) → Nacht dans la ligne de mire si Jundfreud reprennent. Hooks possibles : (a) tuée S57, (b) évacuée à Altdorf, (c) reste en mode résistance impériale.
  • Wagenkneicht S21 : non confirmé agent Nacht. Trois hypothèses (cf. Arc 3 - Ubersreik.md MJ-only S21) — la plus cohérente est (a) Nacht.
  • Bruner épisode : Nacht a sans doute appuyé l'arrestation/incarcération du fils Bruner pour les frasques (cf. fin S15, début S18 quarantaine sur les PJ — peut-être l'a-t-elle organisée pour éviter qu'ils ne s'attachent trop aux Bruner).
  • Réseau Anti-Main-Pourpre : axe central de la Régence. Si les PJ s'allient à Nacht à long terme, ils peuvent recevoir des missions ponctuelles contre des cellules pourpres dans le Reikland.

Hooks de retour

  • Nouvelle mission Filianore Altdorf [S22+] — déclencheur d'arc 4 (Mort sur le Reik). Liée à Etelka Herzen (Couronne Rouge canon DotR ch.4).
  • Témoin Sigmund Jundfreud refait surface : Nacht le sait avant tout le monde, peut envoyer les PJ.
  • Cellule pourpre à Ubersreik : si Engel est révélé agent Tzeentch, Nacht peut commander une frappe.
  • Visite de Karl-Franz à Ubersreik (hypothétique) — Nacht orchestrerait la sécurité, les PJ comme garde rapprochée discrète.
  • Disparition de Nacht (Arc 7 si Jundfreud frappent) : les PJ sont activés pour la retrouver / venger / récupérer ses dossiers.
