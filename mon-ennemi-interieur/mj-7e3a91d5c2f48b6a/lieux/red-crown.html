# Red Crown — Culte de Tzeentch (rival Main Pourpre)

## Identité
- **Allégeance** : **Tzeentch** (rival/concurrent de la Main Pourpre)
- **Type** : Culte secret Tzeentch alternatif. **Hostile à la Main Pourpre** (canon EiS ch.1 l.443).
- **Statut** : [ACTIF] — peu rencontré directement à table
- **Tags** : `#RedCrown` `#Tzeentch` `#RivalMainPourpre` `#DotR` `#Université-Altdorf`

## Source canon
- EiS ch.1 *Wanted: Bold Adventurers* (Ernst Heidlemann) : `Source/Enemy Within Campaign Volume 1 Enemy in Shadows/01 - Wanted- Bold Adventurers.md` lignes 442-461
- **Death on the Reik** + **Death on the Reik Companion** (canon ch.15 *The Red Crown — a GM's Guide*) : `Source/Death on the Reik Companion/22 - CHAPTER 15 THE RED CROWN - A GAMEMASTER'S GUIDE.md`
- **Empire in Ruins Companion** ch.7 *The Changeling* — possibles infos

## Background
- Culte Tzeentch concurrent de la Main Pourpre. **Lutte interne Tzeentch**.
- **Vénère la Couronne Rouge** (signification à creuser dans le Companion DotR).
- **Recrutement** : étudiants universitaires (Altdorf), daemonologues marginaux, magiciens noirs auto-formés.
- **Moins structuré** que la Main Pourpre, plus opportuniste.

## Membres connus
- **Etelka Herzen** [MORTE S25] — sorcière vétéran Red Crown, base régionale Reikland est (mine près de Grissenwald). Tuée aux Collines Stériles par les PJ.
- **Ernst Heidlemann** [MORT S25] — apprenti wizard Altdorf, courrier/éclaireur Red Crown, partenaire opérationnel d'Etelka. Tué avec elle aux Collines Stériles.
- **Doktor Schmidt** [VIVANT, non-rencontré] — daemonologue Université d'Altdorf. Destinataire des préparations Heidlemann. **Rang plus élevé Red Crown probable**. Seul relais Red Crown identifié subsistant après S25.
- **Blackie le corbeau** [STATUT INCONNU] — possible agent au Coach and Horses Inn (canon : *« sent to disrupt the agents of the Red Crown »* — Blackie est anti-Red-Crown).

## Plot Red Crown à Death on the Reik (à venir)
- Canon DotR Companion ch.15 contient les détails complets. À creuser pour Arc 4.
- Signal Tower complot ; **Aynjulls Isembeard** mentionnée (cf. fiche Altdorf). Connexion Red Crown probable.
- Arc 4 canon : **Etelka Herzen + Ernst Heidlemann = même cellule Red Crown** (DotR ch.4 l.6 + l.34). Expédition régionale pour la pierre céleste de Morrslieb. Tous deux tués S25 par les PJ aux Collines Stériles.

## Rivalité Red Crown ↔ Main Pourpre
- Canon EiS ch.1 l.443 explicite : "**a Chaos cult dedicated to Tzeentch and hostile to the Main Pourpre**".
- **Tactique d'utilisation** : si les PJ apprennent l'existence des deux, peuvent les opposer.
- **Différences doctrinales** : à étoffer (Red Crown semble plus "magie pure" vs Pourpre "manipulation politique").

## Hooks de retour
- **Arc 4 (Death on the Reik)** : centre du complot Red Crown. À détailler quand on traitera l'arc.
- **Doktor Schmidt** à l'Université d'Altdorf : cible potentielle pour les PJ qui voudraient remonter la chaîne Red Crown.
- **Confrontation déclenchée** : les PJ exposent un Pourpre à un Red Crown → conflit interne.
- **Recrutement Anselm ?** : Anselm est sorcier renégat. **Potentiel cible de recrutement Red Crown** (qui aime les magiciens auto-formés). Hook narratif intéressant — peut tendre Anselm comme PJ tenté.
