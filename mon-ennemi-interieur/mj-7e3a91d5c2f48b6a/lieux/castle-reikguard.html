Castle Reikguard

Headquarters Grand Order Reiksguard + bolthole Imperial family depuis Gorbad Ironclaw 1707 IC. Résidence Prince Héritier Wolfgang Holswig-Abenauer. Runic anti-magic : Casting Tests -3 SL inside walls. Scène S59 audience Wolfgang + 3 Yeux résidents (Kathe + Per + Ingrid).

Identité

  • Type : Fortified castle sur promontoire 200ft above Reiker Marshes, confluence Teufel + Reik.
  • Fonction : Headquarters Grand Order of the Reiksguard (elite secular order défendant Reikland + Imperial bloodline).
  • Histoire canon (ch.4 l.67-77) : Bolthole Imperial family post-Gorbad Ironclaw invasion 1707 IC. Heavily refortified post-Gorbad withdrawal — Dwarf runic devices repel magic.
  • Apparence canon : « strikes building, tall + imposing, built above Reik on steep cliff side. Pennants Reiksguard heraldry + coat of arms Emperor's family fluttering. Intricate Dwarf runes carved into stonework ».

  • Promontoire : keep + flanking towers >200ft above Reiker Marshes.
  • Confluence Teufel + Reik : strategic river position.
  • Curtain wall : surrounding complex + lesser towers.
  • Main gatehouse : south overlooking broad plain (cleared trees, impossible approche unseen).
  • Inner buildings : training grounds + barracks + armouries + facilités relaxation + observance religieuse.

Restrictions

  • Casting Tests -3 SL : « any Sail Tests made to control the balloon are made with a penalty of -3 SL » — appliqué Channelling+Language Magick.
  • Lores Witchcraft + Necromancy + Daemonology + Chaos : -6 SL.
  • Spell casting socially impolitic.
