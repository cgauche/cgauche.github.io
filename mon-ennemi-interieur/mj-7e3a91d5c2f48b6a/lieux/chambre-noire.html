Chambre Noire MJ

Chambre Noire

Reikland's foremost intelligence network, best-equipped espionage organisation Empire. Notorious Île Noire Altdorf = HQ. Operatives + safe houses Old World wide. Holzkrug runs inner circle ; Immanuel-Ferrand keeps own clandestine network Graukappen (branche externe). Infiltrée Tzeentch via Zuntermein Magister Magistri Altdorf cell Main Pourpre.

Identité

  • Type : Imperial intelligence network, Reikland-based.
  • Quartier général : Île Noire Altdorf — notorious island.
  • Structure canon (Intro l.585-587) : « Liepmund Holzkrug, the high lord ambassador of the Reikland Council, runs the inner circle of the Chambre Noire. Many in Altdorf doubt the wisdom of his appointment, as the Holzkrug family are historic rivals of the Holswig-Schliestein dynasty. Yet, whilst Liepmund is fiery and ambitious, all evidence suggests that he is loyal to the Emperor ».
  • Cercle Intérieur + Spionwerber (recruitment arm — Zuntermein head) + Graukappen (Immanuel-Ferrand external branch).

Hiérarchie

Cercle Intérieur (canon Intro l.589)

  • Liepmund Holzkrug : Grand Ambassadeur, runs Cercle Intérieur. Loyaliste Empereur mais aussi anti-Holswig-Schliestein dynasty.
  • Immanuel-Ferrand Holswig-Schliestein : High Chancellor + member Cercle Intérieur + Grey Order wizard.
  • Yann Zuntermein : adjunct Holzkrug + head Spionwerber + secret Magister Magistri Altdorf cell Main Pourpre.
  • Emmanuelle Nacht : « Top Spy/Diplomat » (canon Intro l.302) — Best agent Immanuel-Ferrand. Envoyée Ubersreik canon. Investigating Main Pourpre pré-redirection.

Spionwerber (recruitment arm Chambre Noire)

  • Head Zuntermein.
  • Diverts Chambre Noire away from Chaos cults = function tâche apparent.
  • Réellement : embed Ordo Terribilis Altdorf parmi spies+diplomats.
  • Agents : Captain Emil Baecker + Spionwerber elite agents.

Graukappen (external arm)

  • Immanuel-Ferrand runs.
  • Intelligence gathering + acting hostile forces outside Altdorf.

Mission canon

  • Intelligence Empire-wide (multiples cellules).
  • Île Noire HQ : « they have operatives and safe houses throughout the Old World » (canon Intro l.585).

Status Tzeentch infiltration

  • Zuntermein Magister Magistri Altdorf cell Main Pourpre : embedded depuis longtemps.
  • Holzkrug ignore Zuntermein cultiste.
  • Immanuel-Ferrand ignore Zuntermein cultiste.
  • Emmanuelle Nacht = best agent Immanuel-Ferrand investigating Main Pourpre → redirected Ubersreik par Zuntermein = neutralised threat (canon Intro l.297).
