# Maisons nobles Empire — Arc 7

> Fiche groupée **maisons nobles électrices Empire Arc 7** + leur rôle climax + History of Turmoil canon (résolution post-climax). Pour Maison Todbringer + Maison Kärzburdger voir fiches dédiées. Pour Maisons Ubersreik voir Maisons nobles d'Ubersreik.

## Maison Holswig-Schliestein (Reikland / Imperial dynasty)

- **Dynastie impériale current**. **Karl-Franz** Emperor. **Isabella** sœur KF (mère Wolfgang). **Luitpold** fils KF disinherited *« enfeeblements »*. **Wolfgang** neveu KF par Isabella = Prince Héritier.
- **Immanuel-Ferrand** = oncle Karl-Franz, High Chancellor.
- **Maria-Luise von Walfen** = concubine KF + mother of his children (Luitpold etc.). Chief Lady of Court informally Empress.
- **Rivale historique : House Holzkrug** (canon).
- **Post-Turmoil canon** : Karl-Franz renewed vigour, reforms Empire.
- Tags : `#HolswigSchliestein` `#Reikland` `#Imperial` `#KarlFranz` `#Wolfgang` `#Luitpold` `#Isabella` `#MariaLuise`

## House Holzkrug (Reikland rival)

- **Grand Ambassadeur Liepmund Holzkrug** runs Chambre Noire Cercle Intérieur.
- **Famille ex-Empereur** : Eberhardt the Just reign 2232-2260 IC. Founded Great Hospice 2243 IC. **Weissbruck canal 2462 IC** completed soutien Emperor Mattheus II remedy ancient rivalry Holswig.
- **Loyaliste Empire mais anti-Holswig dynasty** : conspirateur séculier vendetta.
- **Plot Ubersreik** : work avec Zuntermein fake evidence Jungfreuds + push KF order takeover + publicly decry → KF reputation ruiné.
- Tags : `#Holzkrug` `#Reikland` `#BlackChamber` `#EberhardtTheJust` `#Weissbruck` `#AntiHolswig` `#Ambitieux`

## Maison Todbringer (Middenheim)

→ Fiche dédiée Maison Todbringer (Arc 5+6 documenté). **Arc 7 critical** : Boris mort S63 homebrew. Heinrich héritier de fait. Katarina fiancée Wolfgang. Stefan disinherited inapte.
- **Post-Turmoil canon (invalidé table par S63)** : Boris devait devenir **Grand Duke of Middenland** (annexion Middenland sous Boris). **Table = Heinrich/Dietrich/Heinricus Kärzburdger alternative**.

## Maison Bildhofen (Middenland / Carroburg)

- **Grand Duke Leopold Bildhofen** Elector Middenland.
- **Related Todbringers par mariage** (canon Intro l.249).
- **Descendant Magnus von Bildhofen = Magnus the Pious** — un des plus grands Empereurs Sigmarites.
- **Loyaltés tiraillées** : Middenheim Todbringers vs Holswig-Schliestein Sigmarite lien Magnus.
- **Post-Turmoil canon** : **Bildhofens perdent Middenland** — annexée à Middenheim sous Boris. **Table S63 = invalide** → Heinrich/Heinricus alternative.
- Tags : `#Bildhofen` `#Middenland` `#Carroburg` `#MagnusThePious` `#Sigmar` `#Doomed` `#Todbringer`

## House Toppenheimer (Sudenland)

- **Grand Baroness Etelka Toppenheimer** Elector Sudenland.
- **12 children disinherited** pour fils adoptif **Basil** = scandale interne.
- **8 children secrètement support Emmanuelle** (canon Intro l.26).
- **Sudenland canon = anciennement Solland** (province torn apart par Gorbad Ironclaw 1707 IC).
- **Threshers mercenary warband** : **Fione Brecht** + Sudenland soldats disguised Nuln false flag.
- **Hugo Bottomdown** halfelin spy.
- **Proposition Boris ch.7** : alliance Ulric culte officiel Sudenland en échange aide militaire vs Emmanuelle.
- **Post-Turmoil canon** : **Sudenland annexée Nuln** → Emmanuelle Grand Countess Wissenland. **Etelka perd siège**.
- Tags : `#Toppenheimer` `#Sudenland` `#Solland` `#Basil` `#Pfeildorf` `#FioneBrecht` `#Threshers` `#Doomed`

## Maison Alptraum (Averland)

- **Grand Countess Ludmilla Alptraum** Elector Averland — **vieille + malade**.
- **Marlene Alptraum** fille — belligerent + outflanked par Leitdorf Streissen.
- **Rivalité historique Leitdorf/Leitdorf** Alptraum (canon Intro l.302) — aggravée par Averheim Main Pourpre cell.
- **Streissen Independence Party (SIP)** : fake revolution = Leitdorf op cover Marcus Karlssen.
- **Post-Turmoil canon** : **Alptraums perdent Averland** au profit Marius Leitdorf.
- Tags : `#Alptraum` `#Averland` `#Streissen` `#Ludmilla` `#Marlene` `#Doomed`

## House Leitdorf (Averland montant)

- **Marius Leitdorf** « Mad Count » — ambitieux Elector.
- **Marcus Karlssen** Captain bodyguard Marius cover SIP leader Streissen.
- **Battle Streissen canon** : Marius flanks Alptraum forces → Marlene scattered Averheim.
- **Daisy Kurt von Hellboring II** jument advisor (jab Reiksmarshall Helborg).
- **Post-Turmoil canon** : **Marius Grand Count Averland**. Gain Electorat.
- Tags : `#Leitdorf` `#Leitdorf` `#MariusLeitdorf` `#Averland` `#MadCount` `#Sigmar` `#GoldenAge` `#Streissen`

## House Tasseninck (Ostland)

- **Hans-Hals von Tasseninck** Elector — *« hothead »* canon Intro l.270.
- **Prince Héritier Hergard von Tasseninck** = **MORT** assassiné par Snikkit canon (HR l.699) sur tip-off Main Pourpre. Rumeurs canon orchestrées par Wolfenburg agents blame Krieglitz Talabecland.
- **Ostwald von Konigswald** : ruler ancien doomed corrompu Sudenland baron mercy kill canon Intro l.270.
- **Ostland fiercely Sigmarite**.
- **Post-Turmoil canon** : **Hans-Hals perd Ostland** au profit **Valmir von Raukov** Grand Prince Ostland.
- Tags : `#Tasseninck` `#Ostland` `#HansHals` `#Hergard` `#Sigmar` `#Konigswald` `#vonRaukov` `#Doomed`

## House Krieglitz (Talabecland)

- **Grand Duke Gustav Krieglitz** Elector Talabecland — *« hotheaded »*.
- **Faux blâme Hergard meurtre** par Main Pourpre Wolfenburg agents.
- **Elise Krieglitz-Untern** Grand Duchess Talabheim — perd siège canon.
- **Post-Turmoil canon** : **Krieglitz perdent Talabecland + Talabheim**. **Order of the Silver Hammer** (Witch Hunters) chasse cultistes. **Helmut Feuerbach** unifie Talabheim+Talabecland post-Turmoil.
- Tags : `#Krieglitz` `#Talabecland` `#Talabheim` `#GustavKrieglitz` `#ElisaKrieglitzUntern` `#OrderSilverHammer` `#Feuerbach` `#Doomed`
