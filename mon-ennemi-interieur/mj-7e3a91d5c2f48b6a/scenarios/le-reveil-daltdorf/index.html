# Le réveil d'Altdorf — Hub

> **Scénario homebrew** pour 2-3 sessions. Démarre au matin du **4 Erntezeit 2512 IC**, lendemain de l'assaut nocturne du manoir Helstein (S63). Couvre tout le séjour Altdorf des PJ avant leur départ vers Nuln.
>
> Pour le cadre framework long-terme (3 pistes coffre, calendrier 12 mois, concept Johannes), voir [11 - Cadre Le réveil d'Altdorf](../../notes/11-cadre-le-reveil-daltdorf.html).

## Composition table

**6 PJ Altdorf** : Mark, Elvira (grande prêtresse Rhya), Anselm (sorcier), Yuridika (sorcière), Phineas, Johannes Woblhoffer (nouveau PJ, apprenti gris Grey Order).

**Hors champ** :
- **Dietrich** — ailleurs depuis longtemps (Ferlangst / Kärzburdger), n'apparaît pas.
- **Pesold** — joueur, décide s'il part avec Heinrich pour Middenheim (voir [01 - Briefing Helstein](01-briefing-helstein.html)).
- **Heinrich Todbringer** — présent au manoir le matin puis quitte Altdorf à 11h avec le convoi funéraire.

## Horloge in-game — événements NPC-driven

Les événements suivants se produisent à horaire fixe, **indépendamment des PJ**. Le MJ tient l'horloge ; les PJ choisissent leur tempo dans ce cadre.

| Heure | Événement |
|---|---|
| Aube | [01 - Briefing Helstein](01-briefing-helstein.html) disponible au manoir |
| 8h-11h | Heinrich termine ses préparatifs et reçoit les PJ |
| ~9h-10h30 | Fassbinder attend à sa table habituelle de la salle de lecture (rendez-vous fixé en S62). Agent Spionwerber déjà en place dans la salle, surveillance routinière. |
| ~10h | Spionwerber confirme à Zuntermein que Fassbinder s'est installé pour la matinée avec un groupe d'inconnus (les PJ) |
| ~10h30 | Zuntermein dispatche le commando Templiers depuis la Chambre Noire |
| 11h | Heinrich part en convoi vers Middenheim |
| ~11h | Commando Templiers arrive à la bibliothèque (salle de lecture), arrestation publique |
| 11h15-11h30 | Fassbinder mené hors du bâtiment en menottes |
| 11h30-13h | Fouille de la table et du casier de Fassbinder par Templiers + agent Spionwerber |
| 13h+ | Table et casier scellés. Bibliothèque rouverte avec agent Spionwerber en planque (table proche, fait semblant de lire) |
| 16h-18h | Si **trigger Maria-Luise** activé : billet livré au manoir par Bertholdt |
| 17h-19h | Rumeur « Fassbinder mort en cellule » commence à circuler |
| 22h | Rendez-vous Lina à Hangmann's Gasse (si billet accepté) |
| J+1 aube | La Comète gréée au quai, prête à partir |

## Variantes selon les variables d'état

- **PJ wanted Sigmarite ?** → variante B globale (CVC en chasse, possibles combats imprévus).
- **PJ tachés Fassbinder ?** → variante C globale (suivis Spionwerber, PJ identifiés par témoins ou Spionwerber).
- **PJ ont visité Maria-Luise ?** → Module 5 joué = beaucoup d'acquis (Kappelmuller démasqué, sort Tzeentch confirmé, Zuntermein nommé) ; non = path ouvert mais info perdue.
- **PJ ont fouillé le cabinet de Fassbinder ?** → documents supplémentaires (Yodri vol. 2, lettre chiffrée Wasmeier à Lieberung) mais risque hérésie matérielle.
- **PA Sigmarite** au départ : -8. Selon actions du jour, peut monter ou descendre.

## Flux suggéré par défaut

Si les PJ ne prennent pas d'initiative particulière, le flux le plus probable est :

1. **Matinée** : briefing Helstein → trajet université → glissement Reikerbahn → consultation Fassbinder à la bibliothèque (avant 11h) → arrestation publique → fuite par les sorties de la bibliothèque.
2. **Après-midi** : retour manoir + repos + écoute rumeurs + un ou deux modules au choix (Shallya, Rathaus, enquête Kappelmuller).
3. **Soir** : si trigger Maria-Luise activé → rendez-vous Lina → visite Karl-Franz.
4. **Matin J+1** : départ Comète.

C'est une suggestion d'orientation, pas un railroad. Les PJ peuvent décider :
- de ne pas aller à la bibliothèque consulter Fassbinder (et tout perdre côté marteau)
- d'aller au Rathaus en premier puis Fassbinder dans l'après-midi (déclenche 04b)
- de ne jamais enquêter sur Kappelmuller (pas de billet Maria-Luise, pas de visite Karl-Franz)
- de quitter Altdorf le matin même (scénario s'effondre, leur choix)

Voir [Pacing](pacing.html) pour la version compressée 3h en séance.
