# Pacing — Le réveil d'Altdorf

> Référence transversale du scénario [Le réveil d'Altdorf](index.html).
> Aide à dimensionner la séance selon le temps disponible.
>
> La structure scénario est modulaire (voir [Hub](index.html) §Menu et §Triggers). Les tableaux ci-dessous donnent le **pacing du flux par défaut** — utile si la table suit l'orientation suggérée. Si elle dévie, le MJ adapte en piochant dans le Menu du Hub.

## Version 3h compressée (séance unique, flux par défaut)

Si la table suit le flux par défaut et que tu veux faire tenir le scénario en une seule séance de 3 heures :

| Bloc | Durée | Module |
|---|---|---|
| Setup + briefing | 10-15 min | [01 - Briefing Helstein](01-briefing-helstein.html) |
| Trajet + glissement | 35-45 min | [02 - Trajet vers l'université](02-trajet-vers-luniversite.html) + [03 - Glissement Reikerbahn](03-glissement-reikerbahn.html) |
| Consultation Fassbinder | 25-30 min | [04 - Bureau Fassbinder](04-bureau-fassbinder.html) |
| Arrestation publique | 10-15 min | [05 - Arrestation et fuite](05-arrestation-et-fuite.html) Phase A |
| Fuite par la bibliothèque | 10-15 min | [05 - Arrestation et fuite](05-arrestation-et-fuite.html) Phase B |
| Après-midi (compressé) | 15-25 min | [07 - Après-midi — hub](07-apres-midi-hub.html) + 1-2 options |
| Visite Empereur | 50-60 min | [13 - Approche via Lina](13-approche-via-lina.html) → [14 - Visite Karl-Franz](14-visite-karl-franz.html) |
| Départ | 10 min | [18 - Départ matinal](18-depart-matinal.html) |

**Total** : ~175 min plein + Module 5 (visite Empereur). ~130 min si Maria-Luise non activée.
Buffer 30 min RP imprévu.

## Version étalée (2-3 séances)

Si la table veut creuser, le scénario peut s'étaler sur 2-3 séances :

### Séance 1 — Matin et début d'après-midi (3h)
- Briefing Helstein
- Trajet + glissement + Sigmarites
- Consultation Fassbinder + arrestation publique + fuite
- Retour Helstein
- Quelques rumeurs / repos
- **Cliffhanger** : Maria-Luise les attend le soir (si trigger activé), décision en suspens

### Séance 2 — Après-midi et soirée (3h)
- Mark au temple Shallya
- Elvira au Rathaus
- Enquête Kappelmuller (pistes activées)
- Rumeurs supplémentaires
- Rumeur Fassbinder mort
- Décision visite Maria-Luise
- Approche via Lina
- Briefing Maria-Luise → chambre Karl-Franz
- **Cliffhanger** : capture Kappelmuller / Karl-Franz lucide

### Séance 3 — Sortie d'Altdorf (1-2h en démarrage de séance, puis voyage Nuln)
- Sorciers entrent (détection sort)
- Fin de visite Maria-Luise
- Sommeil court
- Départ matinal + silhouette 2/3
- Démarrage du voyage Nuln (canon ch.9)

## Adaptations selon la table

### Si la table est lente (>3h pour la séance 1 compressée)
Couper :
- [07 - Après-midi — hub](07-apres-midi-hub.html) entièrement (saut direct au soir)
- Le prêcheur Stollenplatz dans [02 - Trajet vers l'université](02-trajet-vers-luniversite.html)
- Réduire les rumeurs

### Si la table est rapide (<3h)
Ajouter :
- Visite Temple Shallya même si pas demandé (cas alternatif)
- Interception CVC dans les Doklands
- Plus de rumeurs

### Si la table veut creuser
Activer toutes les sous-options de [07 - Après-midi — hub](07-apres-midi-hub.html). Étaler sur 2-3 séances.

## Bornes incompressibles

Certaines scènes ne peuvent pas être coupées sans perte :
- [01 - Briefing Helstein](01-briefing-helstein.html) — pose le mandat
- [03 - Glissement Reikerbahn](03-glissement-reikerbahn.html) — première silhouette + cohérence narrative
- [04 - Bureau Fassbinder](04-bureau-fassbinder.html) + [05 - Arrestation et fuite](05-arrestation-et-fuite.html) — moteur principal
- [05 - Arrestation et fuite](05-arrestation-et-fuite.html) — bascule tactique (arrestation publique, témoins universitaires)
- [18 - Départ matinal](18-depart-matinal.html) — silhouette 2/3 + cliffhanger

Tout le reste est modulable.
